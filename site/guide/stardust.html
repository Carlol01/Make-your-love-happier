Stardust best-effort

Stardust non pubblica API né un formato di esportazione documentato.

Che cosa serve: Qualsiasi esportazione JSON o CSV che tu riesca a ottenere (richiesta dati al supporto, GDPR).
Dove va: nel secret del repository o in data/imports/ / sync --file, come indicato sotto.

Procedura

  1. Richiedi i tuoi dati dalle impostazioni dell'app o al supporto.
  2. Prova: 
    python -m cycle_notifier sync --file stardust.csv --dry-run
  3. Se non riconosce nulla, converti il file nel CSV generico o usa il convertitore.

Limiti da conoscere

  • Supporto "best-effort": non abbiamo un campione ufficiale del formato, quindi si usa il parser tollerante.

Affidabilità della fonte: stabile = formato documentato; best-effort = formato non documentato, letto in modo tollerante; non ufficiale = accesso senza API pubblica, può smettere di funzionare.

Sito statico e pubblico: non contiene dati personali. Le previsioni sono stime automatiche, non consigli medici.
