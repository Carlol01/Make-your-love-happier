Natural Cycles best-effort

Natural Cycles permette di scaricare i dati in formato CSV.

Che cosa serve: Un file CSV con una colonna data e una colonna Menstruation.
Dove va: nel secret del repository o in data/imports/ / sync --file, come indicato sotto.

Procedura

  1. Dall'app o dal sito, nelle impostazioni dell'account, cerca l'esportazione dei dati (CSV).
  2. Importalo: 
    python -m cycle_notifier sync --file natural-cycles.csv

Limiti da conoscere

  • Le righe con MENSTRUATION contano come flusso; SPOTTING è escluso a meno che include_spotting = true.
  • Non esiste un'API pubblica; il formato può cambiare.

Affidabilità della fonte: stabile = formato documentato; best-effort = formato non documentato, letto in modo tollerante; non ufficiale = accesso senza API pubblica, può smettere di funzionare.

Sito statico e pubblico: non contiene dati personali. Le previsioni sono stime automatiche, non consigli medici.
