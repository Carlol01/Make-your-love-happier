Clue best-effort

Clue permette di esportare i propri dati in un file .cluedata (JSON).

Che cosa serve: Il file .cluedata.
Dove va: nel secret del repository o in data/imports/ / sync --file, come indicato sotto.

Procedura

  1. Nell'app cerca la funzione di esportazione dei dati nelle impostazioni (la posizione può variare).
  2. Salva il file sul computer.
  3. Importalo: 
    python -m cycle_notifier sync --file i-miei-dati.cluedata

Limiti da conoscere

  • Sono supportati sia il formato recente (elenco di voci type: period) sia quello vecchio (data con day/period); per altre strutture si usa il parser tollerante.
  • Non esiste un'API pubblica: l'importazione è manuale.

Affidabilità della fonte: stabile = formato documentato; best-effort = formato non documentato, letto in modo tollerante; non ufficiale = accesso senza API pubblica, può smettere di funzionare.

Sito statico e pubblico: non contiene dati personali. Le previsioni sono stime automatiche, non consigli medici.
