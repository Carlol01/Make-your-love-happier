Garmin Connect non ufficiale

Per chi registra il ciclo su un dispositivo Garmin: i dati vengono letti con la libreria non ufficiale garminconnect.

Che cosa serve: Nessun file: un token di accesso (GARMIN_TOKENS) o, in alternativa, email e password.
Dove va: nel secret del repository o in data/imports/ / sync --file, come indicato sotto.

Procedura

  1. Installa l'extra in locale: pip install ".[garmin]".
  2. Esegui python -m cycle_notifier garmin-login: inserisci email, password ed eventuale codice MFA. Il comando stampa il token.
  3. Salvalo come secret: 
    gh secret set GARMIN_TOKENS
  4. Solo se non puoi usare i token: secret GARMIN_EMAIL e GARMIN_PASSWORD (sconsigliato: niente MFA).

Limiti da conoscere

  • Non esiste un'API pubblica per questi dati: la libreria imita l'app e può smettere di funzionare in qualsiasi momento; l'uso potrebbe violare i termini di servizio di Garmin.
  • I token scadono: se il workflow segnala un errore Garmin, ripeti garmin-login.
  • Un errore Garmin non blocca la corsa se esistono altre fonti o dati già salvati.

Affidabilità della fonte: stabile = formato documentato; best-effort = formato non documentato, letto in modo tollerante; non ufficiale = accesso senza API pubblica, può smettere di funzionare.

Sito statico e pubblico: non contiene dati personali. Le previsioni sono stime automatiche, non consigli medici.
