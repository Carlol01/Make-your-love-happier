Period Tracker (GP Apps) best-effort

L'app permette di esportare/fare backup dei dati in CSV, secondo la versione.

Che cosa serve: Un file CSV con colonne di inizio e fine ciclo.
Dove va: nel secret del repository o in data/imports/ / sync --file, come indicato sotto.

Procedura

  1. Cerca nelle impostazioni dell'app la funzione di esportazione o backup (CSV).
  2. Importalo: 
    python -m cycle_notifier sync --file period-tracker.csv

Limiti da conoscere

  • Formato non documentato: parser tollerante; verifica sempre il risultato.
  • Se le date sono ambigue (03/04/2026) imposta date_order in config/config.toml (DMY o MDY).

Affidabilità della fonte: stabile = formato documentato; best-effort = formato non documentato, letto in modo tollerante; non ufficiale = accesso senza API pubblica, può smettere di funzionare.

Sito statico e pubblico: non contiene dati personali. Le previsioni sono stime automatiche, non consigli medici.
