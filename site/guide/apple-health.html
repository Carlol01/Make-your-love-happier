Apple Salute (export.zip) stabile

Apple Salute registra il flusso mestruale; l'esportazione è un file ZIP manuale.

Che cosa serve: export.zip (o il suo export.xml estratto).
Dove va: nel secret del repository o in data/imports/ / sync --file, come indicato sotto.

Procedura

  1. Su iPhone apri Salute → tocca la tua foto/iniziali in alto a destra → Esporta tutti i dati salute.
  2. Invia il file export.zip al computer (AirDrop, Files, email a te stesso).
  3. Importalo in locale (il file è spesso di centinaia di MB e contiene molti dati sensibili: non committarlo): 
    python -m cycle_notifier sync --file export.zip
  4. In alternativa estrai export.xml e aprilo nel convertitore (elaborazione nel browser, nessun upload), poi usa il JSON ottenuto con sync --file.

Limiti da conoscere

  • Non esiste un'API cloud per Apple Salute: serve l'esportazione manuale oppure la Scorciatoia iOS automatica.
  • Viene letto solo il flusso mestruale; il sanguinamento intermestruale è ignorato a meno che include_spotting = true.

Affidabilità della fonte: stabile = formato documentato; best-effort = formato non documentato, letto in modo tollerante; non ufficiale = accesso senza API pubblica, può smettere di funzionare.

Sito statico e pubblico: non contiene dati personali. Le previsioni sono stime automatiche, non consigli medici.
