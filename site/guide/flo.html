Flo best-effort

Flo non ha un'API pubblica; è possibile richiedere l'esportazione dei dati personali (GDPR).

Che cosa serve: Il file JSON dell'esportazione dati.
Dove va: nel secret del repository o in data/imports/ / sync --file, come indicato sotto.

Procedura

  1. Nell'app, dalle impostazioni di privacy/account, richiedi la copia dei tuoi dati personali (i nomi delle voci cambiano con le versioni). Riceverai un archivio, di norma via email.
  2. Estrai il file JSON con i cicli (di solito contiene operationalData e campi come period_start_date / period_end_date).
  3. Importalo: 
    python -m cycle_notifier sync --file flo-export.json

Limiti da conoscere

  • Il formato non è documentato: il parser cerca date di inizio/fine in modo tollerante e può sbagliare se Flo cambia struttura.
  • Controlla sempre il risultato con python -m cycle_notifier predict dopo l'importazione.

Affidabilità della fonte: stabile = formato documentato; best-effort = formato non documentato, letto in modo tollerante; non ufficiale = accesso senza API pubblica, può smettere di funzionare.

Sito statico e pubblico: non contiene dati personali. Le previsioni sono stime automatiche, non consigli medici.
